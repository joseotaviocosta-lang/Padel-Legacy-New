# Projeto canônico do Padel Legacy

Esta pasta é o único código-fonte oficial do projeto.

## Regra de trabalho

- Desenvolver somente nesta pasta/repositório.
- ZIPs de fases e sprints são backups de entrega, não projetos paralelos.
- Antes de uma alteração grande, criar um commit/tag ou um ZIP de backup.
- Nunca copiar uma fase antiga por cima do projeto atual sem comparação de versão.

## Estado consolidado

- Tauri e armazenamento nativo.
- Career Hub e múltiplas carreiras.
- Migração automática de schema v1 para v2.
- Jogador e entidades globais isolados por carreira.
- API pública de gameplay organizada por responsabilidade.
