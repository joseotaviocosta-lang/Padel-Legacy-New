# Créditos de áudio

O Replay Broadcast do Padel Legacy não inclui gravações, samples ou arquivos de terceiros.

Todos os efeitos atuais são sintetizados em tempo real com Web Audio API por código original do projeto. As categorias de raquete, quique, parede, rede, torcida, árbitro e interface usam osciladores simples e envelopes procedurais determinísticos.

Não há atribuições externas nesta versão. Qualquer futuro arquivo de áudio deverá registrar aqui autor, origem, licença, alterações e uso no projeto antes de ser incorporado.
